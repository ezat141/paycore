# PayCore M0–M2 Implementation Plan

**Goal:** Build PayCore's first slice: a multi-module Maven repo with an acquirer simulator and a payment-service. The payment-service authorizes, captures and voids card payments, and makes payment creation idempotent so a client retry can neither charge twice nor lose a charge.

**Architecture:** Two independent Spring Boot 4.1 applications in one repo, with no shared code.
- `acquirer-simulator` (`:8091`) is an in-memory stand-in for a card network. It deduplicates on the merchant's reference.
- `payment-service` (`:8083`) is an OAuth2 resource server that verifies AuthCore JWTs itself. It keeps payments and idempotency keys in Postgres, which is the guarantee, and uses Redis as a fail-open fast path.

**Tech Stack:** Java 21, Spring Boot 4.1.0 (Spring Framework 7, Spring Security 7.1, Jackson 3, Hibernate 7), Spring Data JPA + `JdbcClient`, Flyway, PostgreSQL 16, Redis 7 (Lettuce), JUnit 5, MockMvc, Testcontainers 2, JDK `HttpServer` as the fake acquirer.

**Spec:** `docs/specs/2026-09-27-paycore-m0-m2-design.md`. Section references below (§5.3 etc.) point into it.

**Why `PaymentWrites` is separate from `PaymentCreation` and `PaymentTransitions`:** spec §5.3 forbids holding a transaction open across an acquirer call. Putting every `@Transactional` method in one bean, which the flow classes call through its proxy, makes that rule structural. The flow classes are not transactional, so a transaction can't leak across the network call. Calling a `@Transactional` method on `this` would silently bypass the proxy, and this split rules that out.

`acquirer-simulator/src/main/java/com/paycore/acquirer/AuthorizationBook.java`:

```java
package com.paycore.acquirer;

import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Component;
import org.springframework.web.server.ResponseStatusException;

import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

/**
 * In-memory authorizations, keyed by the merchant's reference. {@code computeIfAbsent} makes
 * "have I seen this reference?" and "record it" one atomic step, so two concurrent requests
 * with the same reference cannot both create an authorization.
 */
@Component
class AuthorizationBook {

    record Recorded(Authorization authorization, boolean created) {
    }

    private final Map<String, Authorization> byReference = new ConcurrentHashMap<>();
    private final Map<String, String> referenceById = new ConcurrentHashMap<>();

    Recorded authorize(AuthorizationRequest request) {
        boolean[] created = {false};
        Authorization authorization = byReference.computeIfAbsent(request.reference(), reference -> {
            created[0] = true;
            Authorization fresh = decide(request);
            referenceById.put(fresh.authorizationId(), reference);
            return fresh;
        });
        if (!authorization.sameRequestAs(request)) {
            throw new ResponseStatusException(HttpStatus.CONFLICT,
                    "reference already used for a different authorization");
        }
        return new Recorded(authorization, created[0]);
    }

    private static Authorization decide(AuthorizationRequest request) {
        String id = "auth_" + UUID.randomUUID();
        if ("tok_decline_funds".equals(request.cardToken())) {
            return new Authorization(id, request.reference(), request.amount(), request.currency(),
                    request.cardToken(), AuthorizationStatus.DECLINED, "insufficient_funds");
        }
        return new Authorization(id, request.reference(), request.amount(), request.currency(),
                request.cardToken(), AuthorizationStatus.APPROVED, null);
    }
}
```

`acquirer-simulator/src/main/java/com/paycore/acquirer/AuthorizationController.java`:

```java
package com.paycore.acquirer;

import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.server.ResponseStatusException;

/**
 * Card-token behaviours (spec §6). {@code tok_error} fails before anything is recorded;
 * {@code tok_timeout} is recorded as approved and only then stalls, so the caller times out on
 * a charge that really happened — the case PayCore has to survive.
 */
@RestController
@RequestMapping("/authorizations")
class AuthorizationController {

    private final AuthorizationBook book;
    private final SimulatorProperties properties;

    AuthorizationController(AuthorizationBook book, SimulatorProperties properties) {
        this.book = book;
        this.properties = properties;
    }

    @PostMapping
    AuthorizationResponse authorize(@RequestBody AuthorizationRequest request) throws InterruptedException {
        Thread.sleep(properties.latency());
        if ("tok_error".equals(request.cardToken())) {
            throw new ResponseStatusException(HttpStatus.INTERNAL_SERVER_ERROR, "simulated acquirer failure");
        }
        AuthorizationBook.Recorded recorded = book.authorize(request);
        // Only a new authorization stalls: a retry must find the stored one straight away.
        if (recorded.created() && "tok_timeout".equals(request.cardToken())) {
```

```java
package com.paycore.payment.payment;

import java.util.EnumMap;
import java.util.EnumSet;
import java.util.Map;
import java.util.Set;

/**
 * The payment lifecycle. {@code CAPTURING} and {@code VOIDING} exist so a capture or void is
 * <em>claimed</em> in the database before the acquirer is called (spec §5.3); {@code UNKNOWN}
 * exists because a timeout is not a failure — the card may have been charged.
 */
public enum PaymentStatus {

    PENDING, AUTHORIZED, DECLINED, UNKNOWN, CAPTURING, CAPTURED, VOIDING, VOIDED;

    private static final Map<PaymentStatus, Set<PaymentStatus>> ALLOWED = new EnumMap<>(PaymentStatus.class);

    static {
        ALLOWED.put(PENDING, EnumSet.of(AUTHORIZED, DECLINED, UNKNOWN));
        // A re-drive (spec §7.5) turns an unknown outcome into a definite one.
        ALLOWED.put(UNKNOWN, EnumSet.of(AUTHORIZED, DECLINED));
        ALLOWED.put(AUTHORIZED, EnumSet.of(CAPTURING, VOIDING));
        ALLOWED.put(CAPTURING, EnumSet.of(CAPTURED));
        ALLOWED.put(VOIDING, EnumSet.of(VOIDED));
    }

    public boolean canMoveTo(PaymentStatus next) {
        return ALLOWED.getOrDefault(this, Set.of()).contains(next);
    }
}
```

```java
 * {@link PaymentStatus}'s table throws before anything is written.
 *
 * <p>{@code version} is a wrapper type on purpose: Spring Data treats a {@code null} version as
 * "new" and calls {@code persist} rather than {@code merge} for an application-assigned id.
 */
@Entity
@Table(name = "payments")
public class Payment {

    @Id
    private UUID id;

    @Column(nullable = false, length = 100)
    private String tenant;

    @Column(name = "amount_minor", nullable = false)
    private long amountMinor;

    @JdbcTypeCode(SqlTypes.CHAR)
    @Column(nullable = false, length = 3)
    private String currency;

    @Column(name = "card_token", nullable = false, length = 64)
    private String cardToken;

    @Column(length = 255)
    private String description;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 16)
    private PaymentStatus status;

    @Column(name = "decline_code", length = 64)
    private String declineCode;

    @Column(name = "acquirer_authorization_id", length = 64)
    private String acquirerAuthorizationId;

    @Column(name = "transition_started_at")
    private Instant transitionStartedAt;

    @Version
    private Long version;

    @Column(name = "created_at", nullable = false)
    private Instant createdAt;

    @Column(name = "updated_at", nullable = false)
    private Instant updatedAt;

    protected Payment() {
    }

    public static Payment pending(UUID id, String tenant, long amountMinor, String currency,
                                  String cardToken, String description) {
        Payment payment = new Payment();
        payment.id = id;
        payment.tenant = tenant;
        payment.amountMinor = amountMinor;
        payment.currency = currency;
        payment.cardToken = cardToken;
        payment.description = description;
        payment.status = PaymentStatus.PENDING;
        payment.createdAt = now();
        payment.updatedAt = payment.createdAt;
        return payment;
    }

    public void authorize(String authorizationId) {
        moveTo(PaymentStatus.AUTHORIZED);
        this.acquirerAuthorizationId = authorizationId;
    }

    public void decline(String authorizationId, String declineCode) {
        moveTo(PaymentStatus.DECLINED);
        this.acquirerAuthorizationId = authorizationId;
        this.declineCode = declineCode;
    }

    /** A re-drive that again gets no answer leaves the payment where it was. */
    public void markUnknown() {
        if (status != PaymentStatus.UNKNOWN) {
            moveTo(PaymentStatus.UNKNOWN);
        }
    }

    /** Claims a capture or void before the acquirer is called (spec §5.3). */
    public void beginTransition(PaymentStatus inFlight) {
        moveTo(inFlight);
        this.transitionStartedAt = updatedAt;
    }

    /**
     * Re-claims a stale capture or void. The row changes, so {@code @Version} bumps, so of two
     * concurrent re-drivers exactly one commits.
     */
    public void refreshTransitionClaim() {
        if (status != PaymentStatus.CAPTURING && status != PaymentStatus.VOIDING) {
            throw new IllegalStateException("no transition in flight for a payment that is " + status);
        }
        this.updatedAt = now();
        this.transitionStartedAt = updatedAt;
    }

    public void completeTransition(PaymentStatus done) {
        moveTo(done);
    }

    private void moveTo(PaymentStatus next) {
        if (!status.canMoveTo(next)) {
            throw new IllegalStateException("cannot move a payment from " + status + " to " + next);
        }
        this.status = next;
        this.updatedAt = now();
    }

    /** Postgres keeps microseconds; truncating here makes a stored snapshot equal a reload. */
    private static Instant now() {
        return Instant.now().truncatedTo(ChronoUnit.MICROS);
    }

    public UUID getId() {
        return id;
    }

    public String getTenant() {
        return tenant;
    }

    public long getAmountMinor() {
        return amountMinor;
    }

    public String getCurrency() {
        return currency;
    }

    public String getCardToken() {
        return cardToken;
    }

    public String getDescription() {
        return description;
    }

    public PaymentStatus getStatus() {
        return status;
    }

    public String getDeclineCode() {
        return declineCode;
    }

    public String getAcquirerAuthorizationId() {
        return acquirerAuthorizationId;
    }

    public Instant getTransitionStartedAt() {
        return transitionStartedAt;
    }

    public Long getVersion() {
        return version;
    }

    public Instant getCreatedAt() {
        return createdAt;
    }

    public Instant getUpdatedAt() {
        return updatedAt;
    }
}
```

```java
                            .claim("permissions", permissions);
                    if (tenant != null) {

                    }
                })
                .authorities(new AuthCoreAuthoritiesConverter());
```

```java
package com.paycore.payment.config;

import org.springframework.core.convert.converter.Converter;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.security.core.authority.SimpleGrantedAuthority;
import org.springframework.security.oauth2.jwt.Jwt;

import java.util.Collection;
import java.util.LinkedHashSet;
import java.util.List;
import java.util.Set;

/**
 * Turns AuthCore's three authorization claims into authorities: {@code SCOPE_x} for what the
 * client application was granted, {@code ROLE_x} and bare permissions for what the user may do.
 * Copied from ledger-service rather than shared — the services share a wire contract, not code.
 */
public class AuthCoreAuthoritiesConverter implements Converter<Jwt, Collection<GrantedAuthority>> {

    @Override
    public Collection<GrantedAuthority> convert(Jwt jwt) {
        Set<GrantedAuthority> authorities = new LinkedHashSet<>();
        for (String scope : claimAsList(jwt, "scope")) {
            authorities.add(new SimpleGrantedAuthority("SCOPE_" + scope));
        }
        for (String role : claimAsList(jwt, "roles")) {
            authorities.add(new SimpleGrantedAuthority(role.startsWith("ROLE_") ? role : "ROLE_" + role));
        }
        for (String permission : claimAsList(jwt, "permissions")) {
            authorities.add(new SimpleGrantedAuthority(permission));
        }
        return authorities;
    }

    /** The {@code scope} claim may arrive as a list or as a space-delimited string. */
    private static List<String> claimAsList(Jwt jwt, String claimName) {
        Object claim = jwt.getClaim(claimName);
        if (claim == null) {
            return List.of();
        }
        if (claim instanceof Collection<?> collection) {
            return collection.stream().map(String::valueOf).toList();
        }
        String value = String.valueOf(claim).trim();
        return value.isEmpty() ? List.of() : List.of(value.split("\\s+"));
    }
}
```

```java
package com.paycore.payment.config;

import org.springframework.security.authorization.AuthorizationDecision;
import org.springframework.security.authorization.AuthorizationManager;
import org.springframework.security.authorization.AuthorizationResult;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.security.web.access.intercept.RequestAuthorizationContext;

import java.util.Set;
import java.util.function.Supplier;
import java.util.stream.Collectors;

/**
 * Spec §3.1–3.2, in order: the client's scope <em>and</em> the user's permission, then a tenant.
 *
 * <p>Both authorities are required because they answer different questions. A user holding
 * {@code payments:write} who signs in through a client granted only {@code payments:read}
 * must not write: the scope is the client's ceiling, the permission is the user's right.
 *
 * <p>The tenant check comes second so a token lacking everything is told about permissions
 * first. A token with no tenant — every client-credentials token today — is refused with its
 * own reason, because no amount of extra scope supplies a claim the token structurally lacks.
 */
public final class PaymentsAuthorization implements AuthorizationManager<RequestAuthorizationContext> {

    public static final String INSUFFICIENT_PERMISSION = "insufficient permission";
    public static final String NO_TENANT = "token carries no tenant";

    private final String permission;

    private PaymentsAuthorization(String permission) {
        this.permission = permission;
    }

    public static PaymentsAuthorization requires(String permission) {
        return new PaymentsAuthorization(permission);
    }

    @Override
    public AuthorizationResult authorize(Supplier<? extends Authentication> authentication,
                                         RequestAuthorizationContext context) {
        Authentication current = authentication.get();
        if (current == null) {
            return new DetailedDenial(INSUFFICIENT_PERMISSION);
        }
        Set<String> granted = current.getAuthorities().stream()
                .map(GrantedAuthority::getAuthority)
                .collect(Collectors.toSet());
        if (!granted.contains("SCOPE_" + permission) || !granted.contains(permission)) {
            return new DetailedDenial(INSUFFICIENT_PERMISSION);
        }
        if (!(current.getPrincipal() instanceof Jwt jwt) || isBlank(jwt.getClaimAsString("tenant"))) {
            return new DetailedDenial(NO_TENANT);
        }
        return new AuthorizationDecision(true);
    }

    private static boolean isBlank(String value) {
        return value == null || value.isBlank();
    }
}
```

```java
package com.paycore.payment.error;

import org.springframework.http.HttpStatus;

import java.util.LinkedHashMap;

import java.util.Map;

/**
 * The platform's one error shape — {@code {"error", "status", "path", "detail"?}} — identical
 * to what GateKeeper and ledger-service render. Duplicated, not shared: the services share a
 * wire contract, not code.
 *
 * <p>{@code detail}, when present, is always text this service wrote, never an exception's
 * message, which risks leaking internals the caller has no business seeing.
 */
final class ErrorBody {

    private ErrorBody() {
    }

    static Map<String, Object> of(HttpStatus status, String path) {
        return of(status, path, null);
    }

    static Map<String, Object> of(HttpStatus status, String path, String detail) {
        Map<String, Object> body = new LinkedHashMap<>();
        body.put("error", status.getReasonPhrase().toLowerCase(Locale.ROOT).replace(' ', '_'));
        body.put("status", status.value());
        body.put("path", path);
        if (detail != null) {
            body.put("detail", detail);
        }
        return body;
    }
}
```

```java
/**
 * 403 in the platform shape. Replaces Spring's {@code BearerTokenAccessDeniedHandler}, which
 * leaves the body empty and labels every denial {@code insufficient_scope} — wrong for a

    }

    public void handle(HttpServletRequest request, HttpServletResponse response,
                       AccessDeniedException accessDeniedException) throws IOException {

                && denied.getAuthorizationResult() instanceof DetailedDenial reason
                ? reason.detail()
                : PaymentsAuthorization.INSUFFICIENT_PERMISSION;

        response.setStatus(HttpStatus.FORBIDDEN.value());
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding(StandardCharsets.UTF_8.name());
        objectMapper.writeValue(response.getWriter(), ErrorBody.of(HttpStatus.FORBIDDEN, request.getRequestURI(), detail));
    }
```

```java
import com.paycore.payment.error.JsonAccessDeniedHandler;
import com.paycore.payment.error.JsonAuthenticationEntryPoint;
import jakarta.servlet.DispatcherType;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.annotation.web.configurers.AbstractHttpConfigurer;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter;
import org.springframework.security.web.SecurityFilterChain;

/**
 * payment-service verifies AuthCore's JWTs itself and never authorizes on GateKeeper's
 * {@code X-GK-*} headers: calling :8083 directly is exactly as secure as calling it through
 * the gateway.
 *
 * <p>All authorization is here, not in {@code @PreAuthorize}. Spring MVC resolves and
 * validates a {@code @Valid @RequestBody} before a method-security interceptor runs, so with
 * annotations an unauthorized caller could get a 400 and learn the validation rules. Here,
 * every check completes before the body is read. Deny by default: a path with no rule is
 * refused even with a full token.
 */
@Configuration
@EnableWebSecurity
public class ResourceServerConfig {

    @Bean
    SecurityFilterChain securityFilterChain(HttpSecurity http,
                                            JsonAccessDeniedHandler accessDeniedHandler,
                                            JsonAuthenticationEntryPoint authenticationEntryPoint) throws Exception {
        http
            .authorizeHttpRequests(authorize -> authorize
                // Boot's error page is rendered on an ERROR dispatch of the original request,
                // which already passed this chain; refusing it would turn a 500 into a 403.
```

```java
package com.paycore.payment.support;

import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpServer;
import tools.jackson.databind.json.JsonMapper;

import java.io.IOException;
import java.io.UncheckedIOException;
import java.net.InetSocketAddress;
import java.net.URI;
import java.time.Duration;
import java.util.LinkedHashMap;
import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * The acquirer contract of spec §6, in-process. Same card-token behaviours as the real
 * simulator — {@code tok_timeout} records the approval <em>before</em> stalling — plus the
 * counters and failure switches a test needs.
 */
public final class FakeAcquirer implements AutoCloseable {

    private static final Duration DEFAULT_SLOW_RESPONSE = Duration.ofSeconds(2);

    private static final class Auth {
        final String id;
        final String reference;
        final String declineCode;
        volatile String status;

        Auth(String id, String reference, String status, String declineCode) {
            this.id = id;
            this.reference = reference;
            this.status = status;
            this.declineCode = declineCode;
        }

        Map<String, Object> toJson() {
            Map<String, Object> json = new LinkedHashMap<>();
            json.put("authorizationId", id);
            json.put("reference", reference);
            json.put("status", status);
            json.put("declineCode", declineCode);
            return json;
        }
    }

    private final HttpServer server;
    private final JsonMapper json = JsonMapper.builder().build();
    private final Map<String, Auth> byReference = new ConcurrentHashMap<>();
    private final Map<String, Auth> byId = new ConcurrentHashMap<>();
    private final Map<String, AtomicInteger> authorizeCallsByReference = new ConcurrentHashMap<>();
    private final AtomicInteger captureCalls = new AtomicInteger();
    private final AtomicInteger voidCalls = new AtomicInteger();
    private final AtomicInteger failingActions = new AtomicInteger();
    private volatile Duration authorizeDelay = Duration.ZERO;
    private volatile Duration slowResponse = DEFAULT_SLOW_RESPONSE;

    private FakeAcquirer(HttpServer server) {
        this.server = server;
    }

    public static FakeAcquirer start() {
        try {
            HttpServer server = HttpServer.create(new InetSocketAddress("127.0.0.1", 0), 0);
            FakeAcquirer fake = new FakeAcquirer(server);
            server.createContext("/authorizations", fake::handle);
            server.setExecutor(Executors.newVirtualThreadPerTaskExecutor());
            server.start();
            return fake;
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }

    public URI baseUrl() {
        return URI.create("http://127.0.0.1:" + server.getAddress().getPort());
    }

    public int authorizeCalls(UUID reference) {
        AtomicInteger calls = authorizeCallsByReference.get(reference.toString());
        return calls == null ? 0 : calls.get();
    }

    public int totalAuthorizeCalls() {
        return authorizeCallsByReference.values().stream().mapToInt(AtomicInteger::get).sum();
    }

    /** Distinct authorizations created — a retry that deduplicated does not add one. */
    public int authorizationsRecorded() {
        return byReference.size();
    }

    public int captureCalls() {
        return captureCalls.get();
    }

    public int voidCalls() {
        return voidCalls.get();
    }

    public void authorizeDelay(Duration delay) {
        this.authorizeDelay = delay;
    }

    public void slowResponse(Duration delay) {
        this.slowResponse = delay;
    }

    /** The next {@code count} capture/void calls answer 500 without doing anything. */
    public void failNextActions(int count) {
        failingActions.set(count);
    }

    public void reset() {
        byReference.clear();
        byId.clear();
        authorizeCallsByReference.clear();
        captureCalls.set(0);
        voidCalls.set(0);
        failingActions.set(0);
        authorizeDelay = Duration.ZERO;
        slowResponse = DEFAULT_SLOW_RESPONSE;
    }

    @Override
    public void close() {
        server.stop(0);
    }

    private void handle(HttpExchange exchange) {
        try {
            String[] path = exchange.getRequestURI().getPath().split("/");
            if (!"POST".equals(exchange.getRequestMethod())) {
                send(exchange, 405, Map.of());
            } else if (path.length == 2) {
                authorize(exchange);
            } else if (path.length == 4) {
                act(exchange, path[2], path[3]);
            } else {
                send(exchange, 404, Map.of());
            }
        } catch (IOException | InterruptedException clientGone) {
            // The client timed out and closed the connection while we slept: exactly the case
            // being simulated. Nothing to do.
        } finally {
            exchange.close();
        }
    }

    @SuppressWarnings("unchecked")
    private void authorize(HttpExchange exchange) throws IOException, InterruptedException {
        Map<String, Object> request = json.readValue(exchange.getRequestBody(), Map.class);
        String reference = (String) request.get("reference");
        String cardToken = (String) request.get("cardToken");
        authorizeCallsByReference.computeIfAbsent(reference, r -> new AtomicInteger()).incrementAndGet();
        Thread.sleep(authorizeDelay);

        if ("tok_error".equals(cardToken)) {
            send(exchange, 500, Map.of("error", "simulated acquirer failure"));
            return;
        }
        boolean[] created = {false};
        Auth auth = byReference.computeIfAbsent(reference, r -> {
            created[0] = true;
            boolean declined = "tok_decline_funds".equals(cardToken);
            Auth fresh = new Auth("auth_" + UUID.randomUUID(), r,
                    declined ? "DECLINED" : "APPROVED", declined ? "insufficient_funds" : null);
            byId.put(fresh.id, fresh);
            return fresh;
        });
        if (created[0] && "tok_timeout".equals(cardToken)) {
            Thread.sleep(slowResponse);
        }
        send(exchange, 200, auth.toJson());
    }

    private void act(HttpExchange exchange, String authorizationId, String action) throws IOException {
        (("capture".equals(action)) ? captureCalls : voidCalls).incrementAndGet();
        if (failingActions.getAndUpdate(n -> Math.max(0, n - 1)) > 0) {
            send(exchange, 500, Map.of("error", "simulated acquirer failure"));
            return;
        }
        Auth auth = byId.get(authorizationId);
        if (auth == null) {
            send(exchange, 404, Map.of());
            return;
        }
        String target = "capture".equals(action) ? "CAPTURED" : "VOIDED";
        synchronized (auth) {
            if (!auth.status.equals(target)) {
                if (!auth.status.equals("APPROVED")) {
                    send(exchange, 409, Map.of("error", "cannot move " + auth.status + " to " + target));
                    return;
                }
                auth.status = target;
            }
        }
        send(exchange, 200, Map.of("authorizationId", auth.id, "status", auth.status));
    }

    private void send(HttpExchange exchange, int status, Map<String, ?> body) throws IOException {
        byte[] bytes = json.writeValueAsBytes(body);
        exchange.getResponseHeaders().add("Content-Type", "application/json");
        exchange.sendResponseHeaders(status, bytes.length);
        exchange.getResponseBody().write(bytes);
    }
}
```

```java
package com.paycore.payment.acquirer;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.MediaType;
import org.springframework.http.client.JdkClientHttpRequestFactory;
import org.springframework.stereotype.Component;
import org.springframework.web.client.HttpServerErrorException;
import org.springframework.web.client.ResourceAccessException;
import org.springframework.web.client.RestClient;

import java.net.http.HttpClient;
import java.util.UUID;

/**
 * The only code that talks to the acquirer. No retries, circuit breaker or bulkhead yet (M5):
 * one attempt, bounded by a connect and a read timeout.
 *
 * <p>Timeouts, refused connections and 5xx become {@code NoAnswer}. A 4xx is left to throw:
 * the state machine should make one impossible, so seeing one is a bug worth a 500.
 */
@Component
public class AcquirerClient {

    private static final Logger log = LoggerFactory.getLogger(AcquirerClient.class);

    private record AuthorizationCall(String reference, long amount, String currency, String cardToken) {
    }

    private record AuthorizationReply(String authorizationId, String reference, String status, String declineCode) {
    }

    private record ActionReply(String authorizationId, String status) {
    }

    private final RestClient restClient;

    public AcquirerClient(AcquirerProperties properties) {
        HttpClient httpClient = HttpClient.newBuilder()
                .version(HttpClient.Version.HTTP_1_1)
                .connectTimeout(properties.connectTimeout())
                .build();
        JdkClientHttpRequestFactory requestFactory = new JdkClientHttpRequestFactory(httpClient);
        requestFactory.setReadTimeout(properties.readTimeout());
        this.restClient = RestClient.builder()
                .baseUrl(properties.baseUrl().toString())
                .requestFactory(requestFactory)
                .build();
    }

    /** {@code reference} is our payment id: the acquirer deduplicates on it. */
    public AuthorizeOutcome authorize(UUID reference, long amount, String currency, String cardToken) {
        AuthorizationReply reply;
        try {
            reply = restClient.post()
                    .uri("/authorizations")
                    .contentType(MediaType.APPLICATION_JSON)
                    .body(new AuthorizationCall(reference.toString(), amount, currency, cardToken))
                    .retrieve()
                    .body(AuthorizationReply.class);
        } catch (ResourceAccessException | HttpServerErrorException noAnswer) {
            log.warn("acquirer gave no answer for payment {}: {}", reference, noAnswer.getMessage());
            return new AuthorizeOutcome.NoAnswer();
        }
        return switch (reply.status()) {
            case "APPROVED" -> new AuthorizeOutcome.Approved(reply.authorizationId());
            case "DECLINED" -> new AuthorizeOutcome.Declined(reply.authorizationId(), reply.declineCode());
            default -> throw new IllegalStateException("acquirer returned an unknown status: " + reply.status());
        };
    }

    public ActionOutcome capture(String authorizationId) {
        return act(authorizationId, "capture");
    }

    public ActionOutcome voidAuthorization(String authorizationId) {
        return act(authorizationId, "void");
    }

    private ActionOutcome act(String authorizationId, String action) {
        try {
            restClient.post()
                    .uri("/authorizations/{id}/{action}", authorizationId, action)
                    .retrieve()
                    .body(ActionReply.class);
            return new ActionOutcome.Completed();
        } catch (ResourceAccessException | HttpServerErrorException noAnswer) {
            log.warn("acquirer gave no answer to {} of {}: {}", action, authorizationId, noAnswer.getMessage());
            return new ActionOutcome.NoAnswer();
        }
    }
}
```

```java
package com.paycore.payment.error;

import org.springframework.http.HttpStatus;

import java.util.Map;
import java.util.UUID;

/**
 * A refusal this service decided on, carrying the status and the {@code detail} we wrote.
 * These are expected outcomes, not faults, so no stack trace is captured.
 */
public final class ApiException extends RuntimeException {

    private final HttpStatus status;
    private final String detail;
    private final Map<String, Object> extras;
    private final boolean retryLater;

    private ApiException(HttpStatus status, String detail, Map<String, Object> extras, boolean retryLater) {
        super(detail, null, false, false);
        this.status = status;
        this.detail = detail;
        this.extras = extras;
        this.retryLater = retryLater;
    }

    public static ApiException badRequest(String detail) {
        return new ApiException(HttpStatus.BAD_REQUEST, detail, Map.of(), false);
    }

    public static ApiException notFound() {
        return new ApiException(HttpStatus.NOT_FOUND, "no such payment", Map.of(), false);
    }

    public static ApiException conflict(String detail) {
        return new ApiException(HttpStatus.CONFLICT, detail, Map.of(), false);
    }

    /** 409 with {@code Retry-After: 1}: the thing asked for is happening; ask again shortly. */
    public static ApiException inProgress(String detail) {
        return new ApiException(HttpStatus.CONFLICT, detail, Map.of(), true);
    }

    public static ApiException keyReused() {
        // valueOf, not a constant: Framework 7 renamed 422's constant, and the number is the contract.
        return new ApiException(HttpStatus.valueOf(422),
                "Idempotency-Key was already used with a different request", Map.of(), false);
    }

    /** The acquirer gave no definite answer. {@code paymentId} is present on authorize only. */
    public static ApiException badGateway(String detail, UUID paymentId) {
        Map<String, Object> extras = paymentId == null
                ? Map.of()
                : Map.<String, Object>of("paymentId", paymentId.toString());
        return new ApiException(HttpStatus.BAD_GATEWAY, detail, extras, false);
    }

    public HttpStatus status() {
        return status;
    }

    public String detail() {
        return detail;
    }

    public Map<String, Object> extras() {
        return extras;
    }

    public boolean retryLater() {
        return retryLater;
    }
}
```

```java
package com.paycore.payment.error;

import jakarta.servlet.http.HttpServletRequest;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.dao.OptimisticLockingFailureException;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.validation.FieldError;
import org.springframework.web.ErrorResponse;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.MissingRequestHeaderException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.method.annotation.MethodArgumentTypeMismatchException;
import tools.jackson.databind.exc.UnrecognizedPropertyException;

import java.util.Comparator;
import java.util.Map;
import java.util.stream.Collectors;

/**
 * Renders every failure that reaches MVC in the platform shape. {@code detail} is always text
 * written here — never an exception's message.
 */
@RestControllerAdvice
public class ApiExceptionHandler {

    private static final Logger log = LoggerFactory.getLogger(ApiExceptionHandler.class);

    @ExceptionHandler(ApiException.class)
    ResponseEntity<Map<String, Object>> refused(ApiException e, HttpServletRequest request) {
        ResponseEntity.BodyBuilder response = ResponseEntity.status(e.status());
        if (e.retryLater()) {
            response.header(HttpHeaders.RETRY_AFTER, "1");
        }
        return response.body(ErrorBody.of(e.status(), request.getRequestURI(), e.detail(), e.extras()));
    }

    /** Field names and our own messages, sorted so the detail is stable. */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    ResponseEntity<Map<String, Object>> invalidBody(MethodArgumentNotValidException e, HttpServletRequest request) {
        String detail = e.getBindingResult().getFieldErrors().stream()
                .sorted(Comparator.comparing(FieldError::getField))
                .map(error -> error.getField() + ": " + error.getDefaultMessage())
                .collect(Collectors.joining("; "));
        return badRequest(request, detail);
    }

    @ExceptionHandler(HttpMessageNotReadableException.class)
    ResponseEntity<Map<String, Object>> unreadableBody(HttpMessageNotReadableException e, HttpServletRequest request) {
        for (Throwable cause = e; cause != null; cause = cause.getCause()) {
            if (cause instanceof UnrecognizedPropertyException unknown) {
                return badRequest(request, "unknown field: " + unknown.getPropertyName());
            }
        }
        return badRequest(request, "malformed request body");
    }

    @ExceptionHandler(MissingRequestHeaderException.class)
    ResponseEntity<Map<String, Object>> missingHeader(MissingRequestHeaderException e, HttpServletRequest request) {
        return badRequest(request, e.getHeaderName() + " header is required");
    }

    @ExceptionHandler(MethodArgumentTypeMismatchException.class)
    ResponseEntity<Map<String, Object>> malformedParameter(MethodArgumentTypeMismatchException e, HttpServletRequest request) {
        return badRequest(request, "malformed " + e.getName());
    }

    /** A lost race that escaped the code expecting it: still a conflict, never a 500. */
    @ExceptionHandler(OptimisticLockingFailureException.class)
    ResponseEntity<Map<String, Object>> concurrentModification(HttpServletRequest request) {
        return ResponseEntity.status(HttpStatus.CONFLICT).body(ErrorBody.of(HttpStatus.CONFLICT,
                request.getRequestURI(), "payment was modified concurrently; retry"));
    }

    @ExceptionHandler(Exception.class)
    ResponseEntity<Map<String, Object>> unexpected(Exception e, HttpServletRequest request) {
        if (e instanceof ErrorResponse framework) {
            // Spring MVC's own 4xx (unsupported media type, no such route, ...): keep its status.
            HttpStatus status = HttpStatus.valueOf(framework.getStatusCode().value());
            return ResponseEntity.status(status).body(ErrorBody.of(status, request.getRequestURI()));
        }
        log.error("unhandled failure on {} {}", request.getMethod(), request.getRequestURI(), e);
        return ResponseEntity.internalServerError()
                .body(ErrorBody.of(HttpStatus.INTERNAL_SERVER_ERROR, request.getRequestURI()));
    }

    private static ResponseEntity<Map<String, Object>> badRequest(HttpServletRequest request, String detail) {
        return ResponseEntity.badRequest().body(ErrorBody.of(HttpStatus.BAD_REQUEST, request.getRequestURI(), detail));
    }
}
```

```java
package com.paycore.payment.payment;

import com.paycore.payment.acquirer.AuthorizeOutcome;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.UUID;

/**
 * Every database transaction the payment flows need, and nothing else. The flows that call
 * the acquirer (PaymentCreation, PaymentTransitions) are not transactional and call in here
 * through the Spring proxy — so no transaction can be open across a network call (spec §5.3).
 */
@Service
public class PaymentWrites {

    private final PaymentRepository payments;

    public PaymentWrites(PaymentRepository payments) {
        this.payments = payments;
    }

    /** Tx 1: the PENDING row is committed before the acquirer is called — evidence if we crash. */
    @Transactional
    public Payment startPending(String tenant, PaymentRequest request) {
        return payments.save(Payment.pending(UUID.randomUUID(), tenant, request.amount(),
                request.currency(), request.cardToken(), request.description()));
    }

    /** Tx 2. */
    @Transactional
    public Payment recordAuthorizeOutcome(UUID paymentId, AuthorizeOutcome outcome) {
        Payment payment = payments.findById(paymentId).orElseThrow();
        switch (outcome) {
            case AuthorizeOutcome.Approved approved -> payment.authorize(approved.authorizationId());
            case AuthorizeOutcome.Declined declined -> payment.decline(declined.authorizationId(), declined.declineCode());
            case AuthorizeOutcome.NoAnswer noAnswer -> payment.markUnknown();
        }
        return payment;
    }
}
```

```java
package com.paycore.payment.payment;

import com.paycore.payment.acquirer.AcquirerClient;
import com.paycore.payment.acquirer.AuthorizeOutcome;
import com.paycore.payment.error.ApiException;
import org.springframework.stereotype.Service;

/** The authorize flow (spec §5.3). Deliberately not transactional: see PaymentWrites. */
@Service
public class PaymentCreation {

    static final String UNKNOWN_OUTCOME = "acquirer outcome unknown; retry with the same Idempotency-Key";

    private final PaymentWrites writes;
    private final AcquirerClient acquirer;

    public PaymentCreation(PaymentWrites writes, AcquirerClient acquirer) {
        this.writes = writes;
        this.acquirer = acquirer;
    }

    public PaymentResponse create(String tenant, PaymentRequest request) {
        Payment pending = writes.startPending(tenant, request);
        AuthorizeOutcome outcome = acquirer.authorize(pending.getId(), pending.getAmountMinor(),
                pending.getCurrency(), pending.getCardToken());
        Payment settled = writes.recordAuthorizeOutcome(pending.getId(), outcome);
        if (settled.getStatus() == PaymentStatus.UNKNOWN) {
            throw ApiException.badGateway(UNKNOWN_OUTCOME, settled.getId());
        }
        return PaymentResponse.from(settled);
    }
}
```

```java
import com.paycore.payment.error.ApiException;
import jakarta.validation.Valid;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.security.core.annotation.AuthenticationPrincipal;
import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestHeader;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import java.util.UUID;
import java.util.regex.Pattern;

@RestController
@RequestMapping("/payments")
public class PaymentController {

    /** 1–255 printable ASCII characters, no space (0x21–0x7E). */
    private static final Pattern IDEMPOTENCY_KEY = Pattern.compile("[\\x21-\\x7E]{1,255}");

    private final PaymentCreation creation;
    private final PaymentRepository payments;

    public PaymentController(PaymentCreation creation, PaymentRepository payments) {
        this.creation = creation;
        this.payments = payments;
    }

    @PostMapping
    public ResponseEntity<PaymentResponse> create(@AuthenticationPrincipal Jwt jwt,
                                                  @RequestHeader("Idempotency-Key") String idempotencyKey,
                                                  @Valid @RequestBody PaymentRequest request) {
        requireWellFormed(idempotencyKey);
        return ResponseEntity.status(HttpStatus.CREATED).body(creation.create(tenantOf(jwt), request));
    }

    @GetMapping("/{id}")
    public PaymentResponse get(@AuthenticationPrincipal Jwt jwt, @PathVariable UUID id) {
        return payments.findByIdAndTenant(id, tenantOf(jwt))
                .map(PaymentResponse::from)
                .orElseThrow(ApiException::notFound);
    }

    private static void requireWellFormed(String idempotencyKey) {
        if (!IDEMPOTENCY_KEY.matcher(idempotencyKey).matches()) {
            throw ApiException.badRequest("Idempotency-Key must be 1-255 printable ASCII characters, without spaces");
        }
    }

    /** Always present: PaymentsAuthorization refuses a token without one before any handler runs. */
    private static String tenantOf(Jwt jwt) {
        return jwt.getClaimAsString("tenant");
    }
}
```

```java
    public sealed interface Claim {

        record Claimed(Payment payment) implements Claim {
        }

        record AlreadyDone(Payment payment) implements Claim {
        }
    }

    /**
     * Claims a capture or void (spec §5.3 table). Two racing requests both read version N; the
     * second to commit fails on {@code @Version} and never calls the acquirer.
     */
    @Transactional
    public Claim claimTransition(String tenant, UUID id, TransitionAction action, Duration staleAfter) {
        Payment payment = payments.findByIdAndTenant(id, tenant).orElseThrow(ApiException::notFound);
        PaymentStatus status = payment.getStatus();
        if (status == action.done) {
            return new Claim.AlreadyDone(payment);
        }
        if (status == action.inFlight) {
            if (payment.getTransitionStartedAt().isAfter(Instant.now().minus(staleAfter))) {
                throw ApiException.inProgress(action.verb + " in progress");
            }
            payment.refreshTransitionClaim();
            return new Claim.Claimed(payment);
        }
        if (status == PaymentStatus.AUTHORIZED) {
            payment.beginTransition(action.inFlight);
            return new Claim.Claimed(payment);
        }
        throw ApiException.conflict("cannot " + action.verb + " a payment that is " + status);
    }

    @Transactional
    public Payment completeTransition(UUID id, TransitionAction action) {
        Payment payment = payments.findById(id).orElseThrow();
        // A stale re-drive and the slow original can both arrive here; the second finds it done.
        if (payment.getStatus() != action.done) {
            payment.completeTransition(action.done);
        }
        return payment;
    }
```

```java
package com.paycore.payment.payment;

import com.paycore.payment.acquirer.AcquirerClient;
import com.paycore.payment.acquirer.ActionOutcome;
import com.paycore.payment.error.ApiException;
import org.springframework.dao.OptimisticLockingFailureException;
import org.springframework.stereotype.Service;

import java.util.UUID;

/** Capture and void (spec §5.3). Not transactional: the acquirer call sits between two transactions. */
@Service
public class PaymentTransitions {

    private final PaymentWrites writes;
    private final AcquirerClient acquirer;
    private final PaymentProperties properties;

    public PaymentTransitions(PaymentWrites writes, AcquirerClient acquirer, PaymentProperties properties) {
        this.writes = writes;
        this.acquirer = acquirer;
        this.properties = properties;
    }

    public PaymentResponse capture(String tenant, UUID id) {
        return run(tenant, id, TransitionAction.CAPTURE);
    }

    public PaymentResponse voidPayment(String tenant, UUID id) {
        return run(tenant, id, TransitionAction.VOID);
    }

    private PaymentResponse run(String tenant, UUID id, TransitionAction action) {
        PaymentWrites.Claim claim;
        try {
            claim = writes.claimTransition(tenant, id, action, properties.transitionStaleAfter());
        } catch (OptimisticLockingFailureException lostRace) {
            throw ApiException.conflict("payment was modified concurrently; retry");
        }
        return switch (claim) {
            case PaymentWrites.Claim.AlreadyDone done -> PaymentResponse.from(done.payment());
            case PaymentWrites.Claim.Claimed claimed -> callAcquirer(claimed.payment(), action);
        };
    }

    private PaymentResponse callAcquirer(Payment claimed, TransitionAction action) {
        String authorizationId = claimed.getAcquirerAuthorizationId();
        ActionOutcome outcome = action == TransitionAction.CAPTURE
                ? acquirer.capture(authorizationId)
                : acquirer.voidAuthorization(authorizationId);
        if (outcome instanceof ActionOutcome.NoAnswer) {
            // Left in CAPTURING/VOIDING, never reverted: the acquirer may have done it. Once the
            // claim goes stale a retry re-drives it, which is safe because the acquirer's capture
            // and void are idempotent on the authorization id.
            throw ApiException.badGateway("acquirer outcome unknown; retry the " + action.verb, null);
        }
        return PaymentResponse.from(writes.completeTransition(claimed.getId(), action));
    }
}
```

```java
package com.paycore.payment.idempotency;

import com.paycore.payment.payment.PaymentRequest;
import tools.jackson.databind.json.JsonMapper;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.HexFormat;
import java.util.LinkedHashMap;
import java.util.Map;

/**
 * SHA-256 of the request in a fixed canonical form (spec §7.2): fields in a fixed order, an
 * absent description as {@code null}. Two requests with the same fingerprint are the same
 * request, whatever order or whitespace the client sent them in.
 *
 * <p>Uses its own mapper, not Boot's: a global Jackson setting changed later must never alter
 * stored fingerprints, or every retry against an existing key would become a 422.
 */
public final class Fingerprint {

    private static final JsonMapper CANONICAL = JsonMapper.builder().build();

    private Fingerprint() {
    }

    public static String of(PaymentRequest request) {
        Map<String, Object> canonical = new LinkedHashMap<>();
        canonical.put("amount", request.amount());
        canonical.put("currency", request.currency());
        canonical.put("cardToken", request.cardToken());
        canonical.put("description", request.description());
        byte[] bytes = CANONICAL.writeValueAsString(canonical).getBytes(StandardCharsets.UTF_8);
        return HexFormat.of().formatHex(sha256(bytes));
    }

    private static byte[] sha256(byte[] bytes) {
        try {
            return MessageDigest.getInstance("SHA-256").digest(bytes);
        } catch (NoSuchAlgorithmException impossible) {
            throw new IllegalStateException("every JVM ships SHA-256", impossible);
        }
    }
}
```

```sql
-- primary key alone guarantees one payment per key — Redis in front of it is only a fast path.

    tenant          varchar(100) NOT NULL,
    idempotency_key varchar(255) NOT NULL,

    response_body   jsonb,
    created_at      timestamptz  NOT NULL DEFAULT now(),

    -- A completed key always has a response to replay; an in-progress one never does.
    CHECK ((state = 'COMPLETED') = (response_status IS NOT NULL AND response_body IS NOT NULL))
```

```java
package com.paycore.payment.idempotency;

import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;

import java.time.Duration;
import java.util.Optional;
import java.util.UUID;

/**
 * {@code idempotency_keys}, in SQL. Leases are compared against Postgres's {@code now()}, never a
 * JVM clock, so instances with skewed clocks still agree on who holds a key.
 */
@Repository
public class IdempotencyKeyStore {

    private final JdbcClient jdbc;

    public IdempotencyKeyStore(JdbcClient jdbc) {
        this.jdbc = jdbc;
    }

    /**
     * False when the key already exists. If another transaction has inserted it but not yet
     * committed, Postgres makes this wait for that transaction to finish, then answers correctly.
     */
    public boolean insertIfAbsent(String tenant, String key, String fingerprint, UUID paymentId, Duration lease) {
        return jdbc.sql("""
                        INSERT INTO idempotency_keys (tenant, idempotency_key, fingerprint, payment_id,
                                                      state, locked_until)
                        VALUES (:tenant, :key, :fingerprint, :paymentId, 'IN_PROGRESS',
                                now() + make_interval(secs => :leaseSeconds))
                        ON CONFLICT (tenant, idempotency_key) DO NOTHING""")
                .param("tenant", tenant)
                .param("key", key)
                .param("fingerprint", fingerprint)
                .param("paymentId", paymentId)
                .param("leaseSeconds", seconds(lease))
                .update() == 1;
    }

    public Optional<KeyRecord> find(String tenant, String key) {
        return jdbc.sql("""
                        SELECT fingerprint, payment_id, state, locked_until > now() AS lease_live,
                               response_status, response_body::text AS response_body
                        FROM idempotency_keys
                        WHERE tenant = :tenant AND idempotency_key = :key""")
                .param("tenant", tenant)
                .param("key", key)
                .query((rs, row) -> new KeyRecord(
                        rs.getString("fingerprint"),
                        rs.getObject("payment_id", UUID.class),
                        rs.getString("state"),
                        rs.getBoolean("lease_live"),
                        rs.getObject("response_status", Integer.class),
                        rs.getString("response_body")))
                .optional();
    }

    /**
     * Takes over a key whose lease has lapsed. Concurrent callers serialise on the row lock and
     * the loser re-evaluates the WHERE against the winner's new lease — so exactly one gets true.
     */
    public boolean claimExpired(String tenant, String key, Duration lease) {
        return jdbc.sql("""
                        UPDATE idempotency_keys
                        SET locked_until = now() + make_interval(secs => :leaseSeconds)
                        WHERE tenant = :tenant AND idempotency_key = :key
                          AND state = 'IN_PROGRESS' AND locked_until <= now()""")
                .param("tenant", tenant)
                .param("key", key)
                .param("leaseSeconds", seconds(lease))
                .update() == 1;
    }

    public void complete(String tenant, String key, int responseStatus, String responseBody) {
        jdbc.sql("""
                        UPDATE idempotency_keys
                        SET state = 'COMPLETED', response_status = :status, response_body = CAST(:body AS jsonb)
                        WHERE tenant = :tenant AND idempotency_key = :key""")
                .param("tenant", tenant)
                .param("key", key)
                .param("status", responseStatus)
                .param("body", responseBody)
                .update();
    }

    /** Ends the lease now, so the next retry may re-drive. The row stays IN_PROGRESS. */
    public void release(String tenant, String key) {
        jdbc.sql("""
                        UPDATE idempotency_keys SET locked_until = now()
                        WHERE tenant = :tenant AND idempotency_key = :key""")
                .param("tenant", tenant)
                .param("key", key)
                .update();
    }

    private static double seconds(Duration duration) {
        return duration.toMillis() / 1000.0;
    }
}
```

```java
package com.paycore.payment.payment;

import com.paycore.payment.acquirer.AuthorizeOutcome;
import com.paycore.payment.error.ApiException;
import com.paycore.payment.idempotency.IdempotencyKeyStore;

import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import tools.jackson.databind.ObjectMapper;

import java.time.Duration;
import java.time.Instant;
import java.util.UUID;

/**
 * Every database transaction the payment flows need, and nothing else. The flows that call
 * the acquirer (PaymentCreation, PaymentTransitions) are not transactional and call in here
 * through the Spring proxy — so no transaction can be open across a network call (spec §5.3).
 */
@Service
public class PaymentWrites {

    public sealed interface Start {

        record Created(Payment payment) implements Start {
        }

        record Existing(KeyRecord key) implements Start {
        }
    }

    public sealed interface Claim {

        record Claimed(Payment payment) implements Claim {
        }

        record AlreadyDone(Payment payment) implements Claim {
        }
    }

    private final PaymentRepository payments;
    private final IdempotencyKeyStore keys;
    private final ObjectMapper json;

    public PaymentWrites(PaymentRepository payments, IdempotencyKeyStore keys, ObjectMapper json) {
        this.payments = payments;
        this.keys = keys;
        this.json = json;
    }

    /**
     * Tx 1 (spec §5.3, §7.3): the key and the PENDING payment commit together or not at all.
     * The key goes first — if it already exists, nothing is written.
     */
    @Transactional
    public Start start(String tenant, String idempotencyKey, String fingerprint, PaymentRequest request, Duration lease) {
        UUID id = UUID.randomUUID();
        if (!keys.insertIfAbsent(tenant, idempotencyKey, fingerprint, id, lease)) {
            return new Start.Existing(keys.find(tenant, idempotencyKey).orElseThrow());
        }
        return new Start.Created(payments.save(Payment.pending(id, tenant, request.amount(),
                request.currency(), request.cardToken(), request.description())));
    }

    /**
     * Tx 2: the outcome, and what the key should say about it. A definite outcome completes the
     * key with the response to replay. No answer releases the lease instead — a 502 is never
     * stored, because replaying it would freeze the payment in UNKNOWN for good.
     */
    @Transactional
    public Payment recordAuthorizeOutcome(String tenant, String idempotencyKey, UUID paymentId, AuthorizeOutcome outcome) {
        Payment payment = payments.findById(paymentId).orElseThrow();
        switch (outcome) {
            case AuthorizeOutcome.Approved approved -> payment.authorize(approved.authorizationId());
            case AuthorizeOutcome.Declined declined -> payment.decline(declined.authorizationId(), declined.declineCode());
            case AuthorizeOutcome.NoAnswer noAnswer -> payment.markUnknown();
        }
        if (payment.getStatus() == PaymentStatus.UNKNOWN) {
            keys.release(tenant, idempotencyKey);
        } else {
            keys.complete(tenant, idempotencyKey, HttpStatus.CREATED.value(),
                    json.writeValueAsString(PaymentResponse.from(payment)));
        }
        return payment;
    }

    /**
     * Claims a capture or void (spec §5.3 table). Two racing requests both read version N; the
     * second to commit fails on {@code @Version} and never calls the acquirer.
     */
    @Transactional
    public Claim claimTransition(String tenant, UUID id, TransitionAction action, Duration staleAfter) {
        Payment payment = payments.findByIdAndTenant(id, tenant).orElseThrow(ApiException::notFound);
        PaymentStatus status = payment.getStatus();
        if (status == action.done) {
            return new Claim.AlreadyDone(payment);
        }
        if (status == action.inFlight) {
            if (payment.getTransitionStartedAt().isAfter(Instant.now().minus(staleAfter))) {
                throw ApiException.inProgress(action.verb + " in progress");
            }
            payment.refreshTransitionClaim();
            return new Claim.Claimed(payment);
        }
        if (status == PaymentStatus.AUTHORIZED) {
            payment.beginTransition(action.inFlight);
            return new Claim.Claimed(payment);
        }
        throw ApiException.conflict("cannot " + action.verb + " a payment that is " + status);
    }

    @Transactional
    public Payment completeTransition(UUID id, TransitionAction action) {
        Payment payment = payments.findById(id).orElseThrow();
        // A stale re-drive and the slow original can both arrive here; the second finds it done.
        if (payment.getStatus() != action.done) {
            payment.completeTransition(action.done);
        }
        return payment;
    }
}
```

```java
package com.paycore.payment.payment;

import com.paycore.payment.acquirer.AcquirerClient;
import com.paycore.payment.acquirer.AuthorizeOutcome;
import com.paycore.payment.error.ApiException;
import com.paycore.payment.idempotency.Fingerprint;
import com.paycore.payment.idempotency.IdempotencyKeyStore;
import com.paycore.payment.idempotency.IdempotencyProperties;
import com.paycore.payment.idempotency.KeyRecord;
import org.springframework.stereotype.Service;
import tools.jackson.databind.ObjectMapper;

/**
 * Idempotent payment creation (spec §7) around the authorize flow (spec §5.3). Deliberately
 * not transactional: see PaymentWrites.
 *
 * <p>Postgres is the guarantee. The key row and the PENDING payment are inserted in one
 * transaction, so its primary key alone prevents two payments for one key.
 */
@Service
public class PaymentCreation {

    static final String UNKNOWN_OUTCOME = "acquirer outcome unknown; retry with the same Idempotency-Key";
    static final String IN_PROGRESS = "a request with this Idempotency-Key is in progress";

    private final PaymentWrites writes;
    private final PaymentRepository payments;
    private final IdempotencyKeyStore keys;
    private final AcquirerClient acquirer;
    private final IdempotencyProperties properties;
    private final ObjectMapper json;

    public PaymentCreation(PaymentWrites writes, PaymentRepository payments, IdempotencyKeyStore keys,
                           AcquirerClient acquirer, IdempotencyProperties properties, ObjectMapper json) {
        this.writes = writes;
        this.payments = payments;
        this.keys = keys;
        this.acquirer = acquirer;
        this.properties = properties;
        this.json = json;
    }

    public CreateResult create(String tenant, String idempotencyKey, PaymentRequest request) {
        return throughDatabase(tenant, idempotencyKey, Fingerprint.of(request), request);
    }

    private CreateResult throughDatabase(String tenant, String idempotencyKey, String fingerprint, PaymentRequest request) {
        return switch (writes.start(tenant, idempotencyKey, fingerprint, request, properties.lockTtl())) {
            case PaymentWrites.Start.Created created -> authorize(tenant, idempotencyKey, created.payment());
            case PaymentWrites.Start.Existing existing -> resume(tenant, idempotencyKey, fingerprint, existing.key());
        };
    }

    /** The key already exists (spec §7.4, "PK violation"). */
    private CreateResult resume(String tenant, String idempotencyKey, String fingerprint, KeyRecord key) {
        if (!key.fingerprint().equals(fingerprint)) {
            throw ApiException.keyReused();
        }
        if (key.completed()) {
            return replay(key.responseStatus(), key.responseBody());
        }
        if (key.leaseLive() || !keys.claimExpired(tenant, idempotencyKey, properties.lockTtl())) {
            throw ApiException.inProgress(IN_PROGRESS);
        }
        // The lease lapsed: the earlier attempt got no answer, or its process died with the
        // payment PENDING. Either way, re-drive the same payment (spec §7.5).
        return authorize(tenant, idempotencyKey, payments.findById(key.paymentId()).orElseThrow());
    }

    /**
     * The payment id is the acquirer's reference. On a re-drive, a charge that did go through
     * comes back as that same authorization rather than a second one.
     */
    private CreateResult authorize(String tenant, String idempotencyKey, Payment payment) {
        AuthorizeOutcome outcome = acquirer.authorize(payment.getId(), payment.getAmountMinor(),
                payment.getCurrency(), payment.getCardToken());
        Payment settled = writes.recordAuthorizeOutcome(tenant, idempotencyKey, payment.getId(), outcome);
        if (settled.getStatus() == PaymentStatus.UNKNOWN) {
            throw ApiException.badGateway(UNKNOWN_OUTCOME, settled.getId());
        }
        return CreateResult.fresh(PaymentResponse.from(settled));
    }

    private CreateResult replay(int status, String body) {
        return CreateResult.replay(status, json.readValue(body, PaymentResponse.class));
    }
}
```

```java
package com.paycore.payment.idempotency;

import com.paycore.payment.support.PaymentServiceTest;
import com.paycore.payment.support.Tokens;
import org.junit.jupiter.api.Test;

import java.time.Duration;
import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.TimeUnit;

import static com.paycore.payment.support.Requests.body;
import static org.assertj.core.api.Assertions.assertThat;

class IdempotencyConcurrencyTest extends PaymentServiceTest {

    /**
     * Twenty copies of the same request released at once, with the acquirer slow enough that
     * they overlap. Exactly one charge; everyone else is told to wait or handed the replay.
     */
    @Test
    void twentyConcurrentRetriesProduceOnePaymentAndOneCharge() throws Exception {
        acquirer.authorizeDelay(Duration.ofMillis(300));
        List<Integer> statuses = fire(20, "order-burst");

        assertThat(statuses).allMatch(status -> status == 201 || status == 409).contains(201);
        assertThat(paymentCount()).isEqualTo(1);
        assertThat(acquirer.totalAuthorizeCalls()).isEqualTo(1);
    }

    private List<Integer> fire(int copies, String idempotencyKey) throws Exception {
        ExecutorService pool = Executors.newFixedThreadPool(copies);
        CountDownLatch go = new CountDownLatch(1);
        try {
            List<Future<Integer>> futures = new ArrayList<>();
            for (int i = 0; i < copies; i++) {
                futures.add(pool.submit(() -> {
                    go.await();
                    return create(Tokens.writer("acme"), idempotencyKey, body(1999, "tok_approve"))
                            .andReturn().getResponse().getStatus();
                }));
            }
            go.countDown();
            List<Integer> statuses = new ArrayList<>();
            for (Future<Integer> future : futures) {
                statuses.add(future.get(30, TimeUnit.SECONDS));
            }
            return statuses;
        } finally {
            pool.shutdownNow();
        }
    }
}
```

```java
package com.paycore.payment.idempotency;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.dao.DataAccessException;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.data.redis.core.script.RedisScript;
import org.springframework.stereotype.Component;
import tools.jackson.databind.ObjectMapper;

import java.util.List;
import java.util.Optional;

/**
 * The Redis fast path for idempotency (spec §7.3). It answers replays and turns away concurrent
 * duplicates without a Postgres round trip.
 *
 * <p><strong>It fails open, and that is safe only because it is not the guard.</strong> Every
 * Redis error is logged and treated as a miss or an acquired lock, and the request continues
 * on the Postgres path, whose primary key still allows one payment per key. If anything ever
 * starts relying on this class for correctness, failing open becomes a double-charge bug.
 */
@Component
public class IdempotencyCache {

    private static final Logger log = LoggerFactory.getLogger(IdempotencyCache.class);

    /** Deletes the lock only if we still own it: an expired holder must not delete a newer one. */
    private static final RedisScript<Long> RELEASE_IF_OWNER = new DefaultRedisScript<>("""
            local current = redis.call('GET', KEYS[1])
            if current and string.find(current, ARGV[1], 1, true) then
              return redis.call('DEL', KEYS[1])
            end
            return 0
            """, Long.class);

    public record Entry(String state, String fingerprint, String owner, Integer responseStatus, String responseBody) {

        public boolean completed() {
            return "COMPLETED".equals(state);
        }
    }

    public enum LockResult { ACQUIRED, HELD, UNAVAILABLE }

    private final StringRedisTemplate redis;
    private final ObjectMapper json;
    private final IdempotencyProperties properties;

    public IdempotencyCache(StringRedisTemplate redis, ObjectMapper json, IdempotencyProperties properties) {
        this.redis = redis;
        this.json = json;
        this.properties = properties;
    }

    public Optional<Entry> get(String tenant, String key) {
        try {
            String value = redis.opsForValue().get(redisKey(tenant, key));
            return value == null ? Optional.empty() : Optional.of(json.readValue(value, Entry.class));
        } catch (DataAccessException e) {
            unavailable("read", e);
            return Optional.empty();
        }
    }

    public LockResult tryLock(String tenant, String key, String fingerprint, String owner) {
        try {
            String value = json.writeValueAsString(new Entry("IN_PROGRESS", fingerprint, owner, null, null));
            Boolean set = redis.opsForValue().setIfAbsent(redisKey(tenant, key), value, properties.lockTtl());
            return Boolean.TRUE.equals(set) ? LockResult.ACQUIRED : LockResult.HELD;
        } catch (DataAccessException e) {
            unavailable("lock", e);
            return LockResult.UNAVAILABLE;
        }
    }

    public void complete(String tenant, String key, String fingerprint, int responseStatus, String responseBody) {
        try {
            String value = json.writeValueAsString(new Entry("COMPLETED", fingerprint, null, responseStatus, responseBody));
            redis.opsForValue().set(redisKey(tenant, key), value, properties.responseTtl());
        } catch (DataAccessException e) {
            unavailable("complete", e);
        }
    }

    public void release(String tenant, String key, String owner) {
        try {
            redis.execute(RELEASE_IF_OWNER, List.of(redisKey(tenant, key)), "\"owner\":\"" + owner + "\"");
        } catch (DataAccessException e) {
            unavailable("release", e);
        }
    }

    /**
     * The tenant is length-prefixed, so ("a:b", "c") and ("a", "b:c") stay apart. Without it
     * they would share a Redis key and one tenant could be replayed another's payment.
     */
    static String redisKey(String tenant, String key) {
        return "paycore:idem:" + tenant.length() + ":" + tenant + ":" + key;
    }

    private static void unavailable(String operation, DataAccessException e) {
        log.warn("redis unavailable for idempotency {}; continuing on postgres alone: {}", operation, e.getMessage());
    }
}
```

```java
package com.paycore.payment.payment;

import com.paycore.payment.acquirer.AcquirerClient;
import com.paycore.payment.acquirer.AuthorizeOutcome;
import com.paycore.payment.error.ApiException;
import com.paycore.payment.idempotency.Fingerprint;
import com.paycore.payment.idempotency.IdempotencyCache;
import com.paycore.payment.idempotency.IdempotencyKeyStore;
import com.paycore.payment.idempotency.IdempotencyProperties;
import com.paycore.payment.idempotency.KeyRecord;
import org.springframework.stereotype.Service;
import tools.jackson.databind.ObjectMapper;

import java.util.Optional;
import java.util.UUID;

/**
 * Idempotent payment creation (spec §7) around the authorize flow (spec §5.3). Deliberately
 * not transactional: see PaymentWrites.
 *
 * <p>Postgres is the guarantee. The key row and the PENDING payment are inserted in one
 * transaction, so its primary key alone prevents two payments for one key. Redis sits in
 * front as a fast path only — see IdempotencyCache for why failing open is safe.
 */
@Service
public class PaymentCreation {

    static final String UNKNOWN_OUTCOME = "acquirer outcome unknown; retry with the same Idempotency-Key";
    static final String IN_PROGRESS = "a request with this Idempotency-Key is in progress";

    private final PaymentWrites writes;
    private final PaymentRepository payments;
    private final IdempotencyKeyStore keys;
    private final IdempotencyCache cache;
    private final AcquirerClient acquirer;
    private final IdempotencyProperties properties;
    private final ObjectMapper json;

    public PaymentCreation(PaymentWrites writes, PaymentRepository payments, IdempotencyKeyStore keys,
                           IdempotencyCache cache, AcquirerClient acquirer, IdempotencyProperties properties,
                           ObjectMapper json) {
        this.writes = writes;
        this.payments = payments;
        this.keys = keys;
        this.cache = cache;
        this.acquirer = acquirer;
        this.properties = properties;
        this.json = json;
    }

    /** Spec §7.4, top to bottom. */
    public CreateResult create(String tenant, String idempotencyKey, PaymentRequest request) {
        String fingerprint = Fingerprint.of(request);

        Optional<CreateResult> cached = fromCache(tenant, idempotencyKey, fingerprint);
        if (cached.isPresent()) {
            return cached.get();
        }

        String owner = UUID.randomUUID().toString();
        if (cache.tryLock(tenant, idempotencyKey, fingerprint, owner) == IdempotencyCache.LockResult.HELD) {
            // Another request holds the key right now: answer from what it left, or ask for a retry.
            return fromCache(tenant, idempotencyKey, fingerprint)
                    .orElseThrow(() -> ApiException.inProgress(IN_PROGRESS));
        }
        try {
            CreateResult result = throughDatabase(tenant, idempotencyKey, fingerprint, request);
            cache.complete(tenant, idempotencyKey, fingerprint, result.status(), json.writeValueAsString(result.body()));
            return result;
        } catch (RuntimeException e) {
            // 422, 409, 502 or a fault: none of them completes the key, so give up our lock.
            cache.release(tenant, idempotencyKey, owner);
            throw e;
        }
    }

    /** A completed entry replays; a held one is 409; either with another fingerprint is 422. */
    private Optional<CreateResult> fromCache(String tenant, String idempotencyKey, String fingerprint) {
        Optional<IdempotencyCache.Entry> entry = cache.get(tenant, idempotencyKey);
        if (entry.isEmpty()) {
            return Optional.empty();
        }
        if (!entry.get().fingerprint().equals(fingerprint)) {
            throw ApiException.keyReused();
        }
        if (!entry.get().completed()) {
            throw ApiException.inProgress(IN_PROGRESS);
        }
        return Optional.of(replay(entry.get().responseStatus(), entry.get().responseBody()));
    }

    private CreateResult throughDatabase(String tenant, String idempotencyKey, String fingerprint, PaymentRequest request) {
        return switch (writes.start(tenant, idempotencyKey, fingerprint, request, properties.lockTtl())) {
            case PaymentWrites.Start.Created created -> authorize(tenant, idempotencyKey, created.payment());
            case PaymentWrites.Start.Existing existing -> resume(tenant, idempotencyKey, fingerprint, existing.key());
        };
    }

    /** The key already exists (spec §7.4, "PK violation"). */
    private CreateResult resume(String tenant, String idempotencyKey, String fingerprint, KeyRecord key) {
        if (!key.fingerprint().equals(fingerprint)) {
            throw ApiException.keyReused();
        }
        if (key.completed()) {
            return replay(key.responseStatus(), key.responseBody());
        }
        if (key.leaseLive() || !keys.claimExpired(tenant, idempotencyKey, properties.lockTtl())) {
            throw ApiException.inProgress(IN_PROGRESS);
        }
        // The lease lapsed: the earlier attempt got no answer, or its process died with the
        // payment PENDING. Either way, re-drive the same payment (spec §7.5).
        return authorize(tenant, idempotencyKey, payments.findById(key.paymentId()).orElseThrow());
    }

    /**
     * The payment id is the acquirer's reference. On a re-drive, a charge that did go through
     * comes back as that same authorization rather than a second one.
     */
    private CreateResult authorize(String tenant, String idempotencyKey, Payment payment) {
        AuthorizeOutcome outcome = acquirer.authorize(payment.getId(), payment.getAmountMinor(),
                payment.getCurrency(), payment.getCardToken());
        Payment settled = writes.recordAuthorizeOutcome(tenant, idempotencyKey, payment.getId(), outcome);
        if (settled.getStatus() == PaymentStatus.UNKNOWN) {
            throw ApiException.badGateway(UNKNOWN_OUTCOME, settled.getId());
        }
        return CreateResult.fresh(PaymentResponse.from(settled));
    }

    private CreateResult replay(int status, String body) {
        return CreateResult.replay(status, json.readValue(body, PaymentResponse.class));
    }
}
```

````markdown
# PayCore

Card payment processing for the AuthCore / GateKeeper platform: authorize, capture and void, with **idempotent payment creation — a client retry can neither charge a card twice nor lose a charge that already happened.**

The hard case is the timeout. The acquirer charges the card, then answers too late; the client sees an error and retries. PayCore never records that payment as failed. ## How idempotency works

A key is identified by `(tenant, key)` — two merchants both sending `order-42` have two independent keys. A request's fingerprint is a SHA-256 of its canonical form; the same key with a different fingerprint is a `422` in every state.

**Two layers, one guarantee.**

| Layer | Role | If it is missing |
|---|---|---|
| Postgres `idempotency_keys`, primary key `(tenant, idempotency_key)` | **The guarantee.** Inserted in the same transaction as the `PENDING` payment, so a duplicate cannot pass the primary key | — |
| Redis `paycore:idem:…` | **Fast path.** `SET NX` turns away concurrent duplicates and a cached completed response answers replays, both without a Postgres round trip | Fails open to Postgres |

Failing open is safe *only* because Redis is not the guard. `RedisDownTest` points Redis at a port nothing listens on and still sees one payment under ten concurrent retries.

**The re-drive.** A `502` is never stored as a key's answer — replaying it would freeze the payment in `UNKNOWN` forever. Instead the key's lease is released, and the next retry with the same key and body claims it (`UPDATE … WHERE locked_until <= now()`, which exactly one concurrent retry wins) and calls the acquirer again with the same payment id as its reference. A payment left `PENDING` by a crashed process is re-driven the same way once its lease lapses.

A replay returns the response as it was when the key completed — a snapshot, as Stripe does. `GET /payments/{id}` gives the current state.

## Capture and void

Capture and void **claim** the transition in the database before calling out: `AUTHORIZED → CAPTURING`, guarded by `@Version`. When a capture and a void race, the loser's commit fails, it gets `409`, and it never reaches the acquirer — so PayCore's state and the acquirer's cannot diverge.

No transaction is ever held open across an acquirer call. An unanswered capture stays `CAPTURING` — never reverted, since it may have happened — and after 30 seconds a retry re-drives it, which is safe because the acquirer's capture is idempotent on the authorization id.

## Known limitations

- **Client-credentials tokens cannot create payments.** They carry no `tenant` claim, and a merchant integrating server-to-server is the realistic case — the most significant gap. M7 adds a tenant-bound machine client to AuthCore.
- **`UNKNOWN` payments resolve only when the client retries.** A client that never retries leaves the payment `UNKNOWN`; M5 adds reconciliation against the acquirer.
- **No resilience around the acquirer** beyond timeouts — no retry, circuit breaker or bulkhead (M5).
- **Idempotency rows are never purged.** Redis forgets after 24 hours; Postgres keeps replaying indefinitely.
- **A replay is a snapshot**, not the payment's current state.
- **Full capture only** — no partial captures, refunds or multi-capture.
- **Not behind GateKeeper yet** — no route and no rate limiting until M7.
- **Listing is `limit`-only**, newest first; keyset pagination arrives in M7.
- **The acquirer link is unauthenticated**, by design (see Running it).
````
